# Contributing

This repository is a personal Arduino stepper turntable lab.

## Scope

Good contributions include:

- Documentation improvements.
- Hardware safety notes.
- Pin mapping clarification.
- Arduino build maintenance.

Out of scope:

- Generated Arduino build artifacts.
- Changes that imply motors can be driven directly from Arduino GPIO.

## Checklist

- If `arduino-cli` is available, run `arduino-cli compile --fqbn arduino:avr:uno .`.
- Confirm documentation keeps external stepper driver requirements clear.
