# Release Process

This is a personal Arduino lab repository. Releases are optional.

## Before Release

1. Compile with Arduino IDE or `arduino-cli compile --fqbn arduino:avr:uno .`.
2. Update `CHANGELOG.md`.
3. Confirm README pin mapping and hardware safety notes are accurate.
4. Do not commit generated Arduino build output.
